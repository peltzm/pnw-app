# Kurzanleitungen Orientierungsgespräch

`shots.py` erzeugt die Screenshots direkt aus `orientierungsgespraech-beta.html` (Playwright/Chromium, Musterdaten),
`bau.py` setzt daraus die beiden A4-PDFs im PNW-CI und legt sie unter `/anleitungen/` ab. Pfade im Skript sind auf die
Arbeitsumgebung bezogen (Repo unter `/home/claude/pnw`). Nach sichtbaren Änderungen an der App beide Skripte neu laufen lassen.
